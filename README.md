# Penalty Kick — Browser Mini-Game

A small football penalty game built with JavaScript, HTML, and CSS. Choose a shot direction, watch the goalkeeper react, and track the score.

## Features

- Left, centre, and right shot selection
- Animated goalkeeper and ball interactions
- Score tracking and round reset
- Keyboard controls
- Sound effects generated with the Web Audio API

## Run locally

Clone this repository and open `index.html` in a modern browser. No build tools or package installation are required.

```bash
git clone https://github.com/Erentass6/Penalty-game-js.git
```

## Project structure

- `index.html`, `style.css`, `script.js` — browser entry point and interface
- `src/` — game modules
- `docs/` — project documentation

## Scope

This is a standalone browser game. Scores are local to the current session; it has no backend or online leaderboard.
